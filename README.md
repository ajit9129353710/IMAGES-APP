# 📸 Image Search App

A simple and responsive **Image Search Application** built using **React.js** and **Unsplash API**. Users can search and view high-quality images instantly.

---

## 🚀 Features

- 🔍 Search images using keywords  
- 🌐 Fetch images from Unsplash API  
- 🖼️ Display images dynamically  
- ⌨️ Search using Enter key  
- ⚡ Fast and responsive UI  

---

## 🛠️ Tech Stack

- React.js (Vite)  
- JavaScript (ES6)  
- CSS  
- Unsplash API

## ⚙️ Installation & Setup

1. Clone the repository:
```
git clone https://github.com/your-username/image-search-app.git
```

2. Navigate to project folder:
```
cd image-search-app
```

3. Install dependencies:
```
npm install
```

4. Run the project:
```
npm run dev
```

---

## 🔑 API Setup

1. Go to Unsplash Developer website  
2. Create an app and get your Access Key  
3. Replace in your code:

```js
const ACCESS_KEY = "YOUR_ACCESS_KEY";
```

## 📌 Usage

- Enter a keyword (e.g., nature, cars, coding)  
- Press Enter or click search  
- Images will be displayed instantly
